# Logan Nguyen — Cybersecurity Portfolio

> Personal portfolio website built to showcase my background, projects, and technical skills as a cybersecurity-focused CIS graduate from Florida Gulf Coast University.

🌐 **Live Site:** https://logan5607.github.io/logannguyenportfolio.github.io/

---

## Overview

This is a portfolio site built without any frameworks or templates. The design takes inspiration from terminal interfaces and cybersecurity tooling — dark theme, monospace type, scanline overlays, and a consistent green/cyan color language throughout.

---

## Built With

| Layer | Details |
|---|---|
| Structure | HTML5 |

No JavaScript frameworks. No CSS libraries. No templates.

---

## Features

- Responsive layout with mobile breakpoints
- CSS-only animations and fade-in sequencing
- Terminal-style About section with simulated command output
- Skill cards, project cards, and a timeline-based experience section
- Clipped-corner button and photo frame styling (matches across components)
- Downloadable resume link
- Sections: Hero, About, Skills, Projects, Education, Experience, Contact

Or drag `index.html` into any browser window.
